# 🧠 Universal Trainer: Умный тренажер с ИИ

Добро пожаловать в **Universal Trainer** — это полноценная веб-платформа для обучения программированию и языкам, объединяющая в себе интервальные повторения, интерактивную среду разработки и интеграцию с нейросетями (OpenRouter API).

## ✨ Ключевые возможности

*   **📚 Умное повторение (SM-2):** Алгоритм, который подбирает задачи именно тогда, когда ты начинаешь их забывать.
*   **💻 Мультиязычная песочница:** Запуск и проверка кода прямо в браузере. Поддерживаются языки: **Python, JavaScript, PHP и SQL (SQLite)**.
*   **🤖 ИИ-Интеграция:** 
    *   Генератор задач по любой теме (создает вопросы и скрытые тесты автоматически).
    *   ИИ-Ревьюер кода (пишет замечания к твоему решению, как Senior-разработчик).
    *   ИИ-Подсказки (наводят на мысль, не давая готовый ответ).
*   **🏆 Геймификация:** Система опыта (XP), ранги (от Новичка до Архитектора), медали за достижения в разных языках, ежедневные стрики и тепловая карта активности.
*   **📊 Аналитика:** Подробный профиль с графиками прогресса по каждому языку.
*   **⚙️ Управление контентом (CRUD):** Добавление, редактирование и удаление карточек прямо через веб-интерфейс.
*   **💾 Бэкапы:** Экспорт и импорт всей базы задач и прогресса в ZIP-архив.
*   **✅ Надежность:** Покрытие автотестами (Pytest) для API, базы данных и логики планировщика.

## 🛠 Технологический стек

*   **Backend:** Python, Flask (Blueprints, Service Layer)
*   **База данных:** SQLite (через встроенный модуль `sqlite3`)
*   **Frontend:** HTML5, CSS3, Vanilla JavaScript (Fetch API), CodeMirror (подсветка синтаксиса)
*   **ИИ:** OpenRouter API (модели DeepSeek, Cohere и др.)
*   **Тестирование:** Pytest

## 📁 Архитектура проекта (Модульная)

Мы используем профессиональный подход с разделением ответственности:
*   `app.py` — точка входа, запуск Flask.
*   `blueprints/` — маршруты (Main, Learning, Sandbox, Management).
*   `services/` — бизнес-логика (проверка кода, загрузка задач).
*   `core/` — ядро приложения (БД, планировщик SM-2, работа с ИИ, достижения).
*   `modules/` — JSON-базы задач.
*   `templates/` — HTML-шаблоны (Jinja2).
*   `tests/` — Pytest тесты.

## 🚀 Как запустить локально

1. Клонируйте репозиторий:
   ```bash
   git clone https://github.com/KinGsToN-dev/trainer.git

cd trainer
2.Создайте виртуальное окружение и активируйте его:

python -m venv .venv
# Windows:
.venv\Scripts\activate
# Mac/Linux:
source .venv/bin/activate


3.Установите зависимости:

pip install -r requirements.txt

4.Настройте API-ключ (для работы ИИ):
Создайте файл .env в корневой папке и добавьте туда:

text
OPENROUTER_API_KEY=ваш_ключ_из_openrouter

5.Запустите сервер:

python app.py
Приложение будет доступно по адресу: http://127.0.0.1:5000

🧪 Запуск тестов
Чтобы убедиться, что всё работает как часы, выполните:


python -m pytest tests/ -v
Создано с любовью к чистому коду и обучению.
